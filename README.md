# 指数的研究：静态站点

## 定位

- 与 `investment-signal` 完全独立；
- 首页列出各指数的独立研究；
- `/hs300/` 展示沪深300全生命周期策略和手工仓位测算；
- 无后台、无账户接口、无埋点；
- 公开仓库只保存460300每日确认净值；
- 用户本金、盈亏和加仓记录保存在当前浏览器 localStorage，不进入仓库。

## 沪深300账本口径

- 策略总本金默认 100,000 元，其中长期储备现金 40,000 元；
- 沪深300最终目标本金为 60,000 元；
- 尚未投入建仓资金 = 总本金 − 长期储备现金 − 沪深300累计投入本金；
- 初始份额 =（初始持仓本金 + 初始盈亏）÷ 初始化日最新确认净值；
- 当前基金市值 = 累计份额 × 最新确认净值；
- 当前组合市值 = 基金市值 + 长期储备现金 + 尚未投入建仓资金；
- 加仓只记录用户已经完成的操作，不会触发真实申购；
- 模型差额不包含具体产品的申赎限制、滑点、税费或个人限制。

## 自动净值

- `scripts/update_fund_nav.py` 拉取460300最新确认净值；
- `update-fund-nav.yml` 在工作日北京时间21:15运行并仅在净值变化时提交；
- 数据源失败时 workflow 失败并保留上一份成功数据，不写空值。

## 本地预览

在 `site/` 目录启动任意静态文件服务器，然后打开 `/hs300/`。站点使用相对路径，可直接部署到独立域名或 GitHub Pages 项目站点。
