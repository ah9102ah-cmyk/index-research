# 指数的研究：静态站点

## 定位

- 与 `investment-signal` 完全独立；
- 首页列出各指数的独立研究；
- `/hs300/` 展示沪深300全生命周期策略、公开远程持仓账本和自动测算；
- 无后台、无账户接口、无埋点；
- 公开仓库保存460300每日确认净值及用户明确授权公开的策略账本；
- 页面没有 GitHub 写入密钥，只读取远程账本；加仓登记由仓库所有者确认后通过 GitHub Actions 写入。

## 沪深300账本口径

- 策略总本金默认 100,000 元，其中长期储备现金 40,000 元；
- 沪深300最终目标本金为 60,000 元；
- 尚未投入建仓资金 = 总本金 − 长期储备现金 − 沪深300累计投入本金；
- 初始份额 =（初始持仓本金 + 初始盈亏）÷ 初始化日最新确认净值；
- 当前基金市值 = 累计份额 × 最新确认净值；
- 当前组合市值 = 基金市值 + 长期储备现金 + 尚未投入建仓资金；
- 加仓只记录用户已经完成的操作，不会触发真实申购；
- 初始账本公开记录：总策略本金100,000元、460300持仓本金39,571.42元、初始盈利1,312.77元、长期储备现金40,000元；
- `data/ledger-460300.json` 是唯一远程账本源，浏览器缓存仅在远程暂时不可用时兜底；
- 模型差额不包含具体产品的申赎限制、滑点、税费或个人限制。

## 自动净值

- `scripts/update_fund_nav.py` 拉取460300最新确认净值；
- `update-fund-nav.yml` 在工作日北京时间21:30、22:30检查，并仅在净值变化时提交；
- 数据源失败时 workflow 失败并保留上一份成功数据，不写空值。

## 远程加仓登记

- 页面填写已完成的加仓后，会生成带结构化数据的 GitHub issue；
- 只有仓库所有者 `ah9102ah-cmyk` 创建的指定登记单会触发写入；
- `record-purchase.yml` 再次校验日期、金额、剩余建仓资金和份额后才追加到账本；
- 未填确认份额时暂按最新确认净值估算，并在账本和页面明确标记；
- 工作流完成后自动关闭登记 issue，Pages 随提交重新部署。

## 本地预览

在 `site/` 目录启动任意静态文件服务器，然后打开 `/hs300/`。站点使用相对路径，可直接部署到独立域名或 GitHub Pages 项目站点。
