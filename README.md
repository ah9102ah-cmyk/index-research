# 指数的研究：静态站点

## 定位

- 与 `investment-signal` 完全独立；
- 首页列出各指数的独立研究；
- `/hs300/` 展示沪深300全生命周期策略和手工仓位测算；
- 无后台、无账户接口、无行情接口、无埋点；
- 用户输入仅存在于当前页面内存，刷新即清空。

## 沪深300页面口径

- “沪深300计划目标仓位”默认 100,000 元，指最终希望持有的沪深300市值；
- 沪深300占完整模型组合 60%，因此对应初始模型资金约 166,666.67 元、长期储备目标约 66,666.67 元；
- 当前持仓成本 = 当前市值 − 累计盈亏；
- 未填写储备资产时，储备资产 = 沪深300目标仓位 ÷ 60% − 当前持仓成本；
- 当前组合市值 = 当前沪深300市值 + 当前储备资产；
- 盈亏只用于还原成本和展示，不参与规则判断；
- 模型差额不包含具体产品的申赎限制、滑点、税费或个人限制。

## 本地预览

在 `site/` 目录启动任意静态文件服务器，然后打开 `/hs300/`。站点使用相对路径，可直接部署到独立域名或 GitHub Pages 项目站点。
